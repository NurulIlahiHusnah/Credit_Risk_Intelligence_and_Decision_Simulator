Pengantar Algoritma Berbasis Pohon

Algoritme berbasis pohon dianggap sebagai salah satu metode pembelajaran terawasi terbaik dan paling banyak digunakan. Algoritme berbasis pohon memberdayakan model prediktif dengan akurasi tinggi, stabilitas, dan kemudahan interpretasi. Berbeda dengan model linier, model ini memetakan hubungan nonlinier dengan cukup baik. Mereka mudah beradaptasi dalam memecahkan segala jenis masalah yang ada (klasifikasi atau regresi).

Metode seperti pohon keputusan, hutan acak, peningkatan gradien populer digunakan dalam semua jenis masalah ilmu data. Oleh karena itu, bagi setiap analis (juga yang lebih baru), penting untuk mempelajari algoritma ini dan menggunakannya untuk pemodelan.

1. Apa yang dimaksud dengan Pohon Keputusan? Bagaimana cara kerjanya ?

Pohon keputusan adalah jenis algoritma pembelajaran terawasi (memiliki variabel target yang telah ditentukan sebelumnya) yang banyak digunakan dalam masalah klasifikasi. Ini berfungsi untuk variabel input dan output kategorikal dan berkelanjutan. Dalam teknik ini, kita membagi populasi atau sampel menjadi dua atau lebih kumpulan (atau sub-populasi) yang homogen berdasarkan pemisah/pembeda yang paling signifikan dalam variabel masukan.

Berpartisipasilah sekarang

Contoh:-

Katakanlah kita memiliki sampel 30 siswa dengan tiga variabel Jenis Kelamin (Laki-laki/Perempuan), Kelas (IX/ X) dan Tinggi Badan (5 hingga 6 kaki). 15 dari 30 orang ini bermain kriket di waktu senggang. Sekarang, saya ingin membuat model untuk memprediksi siapa yang akan bermain kriket di waktu senggang? Dalam permasalahan ini, kita perlu memisahkan siswa yang bermain kriket di waktu senggang berdasarkan variabel masukan yang sangat signifikan di antara ketiganya.

Di sinilah pohon keputusan membantu, ia akan memisahkan siswa berdasarkan semua nilai dari tiga variabel dan mengidentifikasi variabel tersebut, yang menghasilkan kumpulan siswa homogen terbaik (yang heterogen satu sama lain). Pada cuplikan di bawah, Anda dapat melihat bahwa variabel Gender mampu mengidentifikasi himpunan homogen terbaik dibandingkan dengan dua variabel lainnya.

Seperti disebutkan di atas, pohon keputusan mengidentifikasi variabel paling signifikan dan nilainya yang memberikan kumpulan populasi homogen terbaik. Sekarang pertanyaan yang muncul adalah, bagaimana cara mengidentifikasi variabel dan pemisahannya? Untuk melakukan hal ini, pohon keputusan menggunakan berbagai algoritma, yang akan kita bahas di bagian berikut.

Jenis Pohon Keputusan

Jenis pohon keputusan didasarkan pada jenis variabel target yang kita miliki. Ini bisa terdiri dari dua jenis:

  1. Pohon Keputusan Variabel Kategoris:  Pohon Keputusan yang mempunyai variabel target kategorikal maka disebut pohon keputusan variabel kategori. Contoh:- Dalam skenario permasalahan siswa di atas, dimana variabel targetnya adalah “Siswa akan bermain kriket atau tidak” yaitu YA atau TIDAK.
  2. Pohon Keputusan Variabel Berkelanjutan:  Pohon Keputusan mempunyai variabel target yang berkesinambungan sehingga disebut Pohon Keputusan Variabel Berkelanjutan.

Contoh:-  Katakanlah kita mempunyai masalah dalam memprediksi apakah seorang pelanggan akan membayar premi perpanjangannya pada perusahaan asuransi (ya/tidak). Di sini kita mengetahui bahwa pendapatan pelanggan merupakan variabel yang signifikan tetapi perusahaan asuransi tidak memiliki rincian pendapatan untuk seluruh pelanggan. Nah, seperti yang kita ketahui bahwa ini merupakan variabel penting, selanjutnya kita dapat membangun pohon keputusan untuk memprediksi pendapatan pelanggan berdasarkan pekerjaan, produk dan berbagai variabel lainnya. Dalam hal ini, kami memperkirakan nilai variabel kontinu.

Terminologi Penting terkait Algoritma Berbasis Pohon

Mari kita lihat terminologi dasar yang digunakan dengan Pohon Keputusan:

  1. Node Akar:  Ini mewakili seluruh populasi atau sampel dan selanjutnya dibagi menjadi dua atau lebih kumpulan homogen.
  2. Pemisahan:  Ini adalah proses membagi sebuah node menjadi dua atau lebih sub-node.
  3. Node Keputusan:  Ketika sebuah sub-node dipecah menjadi sub-node selanjutnya, maka itu disebut simpul keputusan.
  4. Leaf/ Terminal Node:  Node yang tidak terbelah disebut Leaf atau Terminal node.
  5. Pemangkasan:  Saat kita menghapus sub-node dari node keputusan, proses ini disebut pemangkasan. Anda bisa mengatakan sebaliknya proses pemisahan.
  6. Cabang / Sub-Pohon:  Sub-bagian dari keseluruhan pohon disebut cabang atau sub-pohon.
  7. Node Induk dan Anak:  Suatu node yang terbagi menjadi sub-node disebut node induk dari sub-node sedangkan sub-node adalah anak dari node induk.

Ini adalah istilah yang biasa digunakan untuk pohon keputusan. Seperti yang kita ketahui bahwa setiap algoritma memiliki kelebihan dan kekurangan, berikut adalah faktor-faktor penting yang perlu diketahui.

Keuntungan

  1. Mudah Dipahami : Keluaran pohon keputusan sangat mudah dipahami bahkan oleh orang-orang yang berlatar belakang non-analitis. Tidak diperlukan pengetahuan statistik untuk membaca dan menafsirkannya. Representasi grafisnya sangat intuitif dan pengguna dapat dengan mudah menghubungkan hipotesis mereka.
  2. Berguna dalam Eksplorasi Data:  Pohon keputusan adalah salah satu cara tercepat untuk mengidentifikasi variabel paling signifikan dan hubungan antara dua variabel atau lebih. Dengan bantuan pohon keputusan, kita dapat membuat variabel/fitur baru yang memiliki kekuatan lebih baik dalam memprediksi variabel target. Anda dapat merujuk artikel ( Trik untuk meningkatkan kekuatan model regresi ) untuk salah satu trik tersebut. Ini juga dapat digunakan dalam tahap eksplorasi data. Misalnya, kita sedang mengerjakan suatu masalah di mana kita memiliki informasi yang tersedia dalam ratusan variabel, di sana pohon keputusan akan membantu mengidentifikasi variabel yang paling signifikan.
  3. Lebih sedikit pembersihan data yang diperlukan:  Dibutuhkan lebih sedikit pembersihan data dibandingkan dengan beberapa teknik pemodelan lainnya. Hal ini tidak dipengaruhi oleh outlier dan nilai yang hilang sampai tingkat tertentu.
  4. Tipe data bukan merupakan batasan:  Tipe data dapat menangani variabel numerik dan kategorikal.
  5. Metode Non Parametrik:  Pohon keputusan dianggap sebagai metode non-parametrik. Artinya pohon keputusan tidak memiliki asumsi mengenai distribusi ruang dan struktur pengklasifikasi.

Kekurangan

  1. Over fitting:  Over fitting adalah salah satu kesulitan paling praktis untuk model pohon keputusan. Masalah ini diselesaikan dengan menetapkan batasan pada parameter model dan pemangkasan (dibahas secara rinci di bawah).
  2. Tidak cocok untuk variabel kontinu : Saat bekerja dengan variabel numerik kontinu, pohon keputusan kehilangan informasi ketika mengkategorikan variabel dalam kategori yang berbeda.

2. Pohon Regresi vs Pohon Klasifikasi

Kita semua tahu bahwa simpul terminal (atau daun) terletak di bagian bawah pohon keputusan. Artinya, pohon keputusan biasanya digambar terbalik sehingga daun berada di bagian bawah dan akar berada di bagian atas (ditunjukkan di bawah).

Kedua pohon tersebut bekerja hampir mirip satu sama lain, mari kita lihat perbedaan & persamaan utama antara pohon klasifikasi dan regresi:

  1. Pohon regresi digunakan ketika variabel terikat bersifat kontinu. Pohon klasifikasi digunakan ketika variabel terikat bersifat kategoris.
  2. Dalam kasus pohon regresi, nilai yang diperoleh node terminal dalam data pelatihan adalah respons rata-rata observasi yang berada di wilayah tersebut. Jadi, jika observasi data tak terlihat berada di wilayah tersebut, kita akan membuat prediksinya dengan nilai rata-rata.
  3. Dalam kasus pohon klasifikasi, nilai (kelas) yang diperoleh simpul terminal dalam data pelatihan adalah mode observasi yang berada di wilayah tersebut. Jadi, jika observasi data tak terlihat berada di wilayah tersebut, kita akan membuat prediksinya dengan nilai mode.
  4. Kedua pohon tersebut membagi ruang prediktor (variabel independen) menjadi wilayah yang berbeda dan tidak tumpang tindih. Demi kesederhanaan, Anda dapat menganggap wilayah ini sebagai kotak atau kotak berdimensi tinggi.
  5. Kedua pohon tersebut mengikuti pendekatan serakah dari atas ke bawah yang dikenal sebagai pemisahan biner rekursif. Kami menyebutnya 'top-down' karena dimulai dari puncak pohon ketika semua pengamatan tersedia dalam satu wilayah dan secara berturut-turut membagi ruang prediktor menjadi dua cabang baru di bawah pohon. Hal ini dikenal sebagai 'serakah' karena, algoritme (mencari variabel terbaik yang tersedia) hanya peduli pada pemisahan saat ini, dan bukan pada pemisahan di masa depan yang akan menghasilkan pohon yang lebih baik.
  6. Proses pemisahan ini dilanjutkan hingga kriteria penghentian yang ditentukan pengguna tercapai. Misalnya: kita dapat memerintahkan algoritme untuk berhenti ketika jumlah observasi per node kurang dari 50.
  7. Dalam kedua kasus tersebut, proses pembelahan menghasilkan pohon yang tumbuh sempurna hingga kriteria berhenti tercapai.Namun, pohon yang sudah dewasa kemungkinan akan melakukan overfit pada data, sehingga menghasilkan akurasi yang buruk pada data yang tidak terlihat. Ini membawa 'pemangkasan'. Pemangkasan merupakan salah satu teknik yang digunakan untuk mengatasi overfitting. Kita akan mempelajarinya lebih lanjut di bagian berikut.

3. Bagaimana algoritma berbasis pohon menentukan lokasi pemisahan?

Keputusan untuk melakukan pemisahan strategis sangat mempengaruhi keakuratan pohon. Kriteria keputusan berbeda untuk pohon klasifikasi dan regresi.

Pohon keputusan menggunakan beberapa algoritma untuk memutuskan untuk membagi sebuah node menjadi dua atau lebih sub-node. Pembuatan sub-node meningkatkan homogenitas sub-node yang dihasilkan. Dengan kata lain, kita dapat mengatakan bahwa kemurnian node meningkat sehubungan dengan variabel target. Pohon keputusan membagi node pada semua variabel yang tersedia dan kemudian memilih pemisahan yang menghasilkan sub-node paling homogen.

Pemilihan algoritma juga didasarkan pada jenis variabel target. Mari kita lihat empat algoritma yang paling umum digunakan dalam pohon keputusan:

Gini

Gini mengatakan, jika kita memilih dua item dari suatu populasi secara acak maka item tersebut harus berada di kelas yang sama dan probabilitasnya adalah 1 jika populasinya murni.

  1. Ia bekerja dengan variabel target kategori "Sukses" atau "Kegagalan".
  2. Ia hanya melakukan pemisahan Biner
  3. Semakin tinggi nilai Gini maka semakin tinggi pula homogenitasnya.
  4. CART (Pohon Klasifikasi dan Regresi) menggunakan metode Gini untuk membuat pemisahan biner.

Langkah-langkah Menghitung Gini untuk perpecahan

  1. Hitung Gini untuk sub-node, menggunakan rumus jumlah kuadrat probabilitas keberhasilan dan kegagalan (p^2+q^2).
  2. Hitung Gini untuk pemisahan menggunakan skor Gini tertimbang dari setiap node pemisahan tersebut

Contoh: – Mengacu pada contoh di atas, dimana kita ingin memisahkan siswa berdasarkan variabel target (bermain kriket atau tidak). Pada cuplikan di bawah, kami membagi populasi menggunakan dua variabel input Gender dan Kelas. Sekarang, saya ingin mengidentifikasi pemisahan mana yang menghasilkan sub-node yang lebih homogen menggunakan Gini.

Terbagi berdasarkan Gender:

  1. Hitung, Gini untuk sub-node Female = (0.2)*(0.2)+(0.8)*(0.8)=0.68
  2. Gini untuk sub-node Pria = (0,65)*(0,65)+(0,35)*(0,35)=0,55
  3. Hitung Gini tertimbang untuk Gender Terpisah = (10/30)*0,68+(20/30)*0,55 = 0,59

Mirip dengan Split di Kelas:

  1. Gini untuk sub-node Kelas IX = (0,43)*(0,43)+(0,57)*(0,57)=0,51
  2. Gini untuk sub-node Kelas X = (0,56)*(0,56)+(0,44)*(0,44)=0,51
  3. Hitung Gini tertimbang untuk Kelas Terpisah = (14/30)*0,51+(16/30)*0,51 = 0,51

Di atas terlihat bahwa skor Gini untuk Split on Gender lebih tinggi daripada Split on Class,  oleh karena itu, pemisahan node akan dilakukan berdasarkan Gender.

Anda mungkin sering menjumpai istilah 'Gini Impurity' yang ditentukan dengan mengurangkan nilai gini dengan 1. Jadi secara matematis bisa kita katakan,

Pengotor Gini = 1-Gini

Chi-Square

Ini adalah algoritma untuk mengetahui signifikansi statistik antara perbedaan antara sub-node dan node induk. Kami mengukurnya dengan jumlah kuadrat perbedaan standar antara frekuensi variabel target yang diamati dan yang diharapkan.

  1. Ia bekerja dengan variabel target kategori "Sukses" atau "Kegagalan".
  2. Itu dapat melakukan dua atau lebih split.
  3. Semakin tinggi nilai Chi-Square semakin tinggi signifikansi statistik perbedaan antara sub-node dan node Induk.
  4. Chi-Square setiap node dihitung menggunakan rumus,
  5. Chi-kuadrat = ((Realisasi – Ekspektasi)^2 / Ekspektasi)^1/2
  6. Ini menghasilkan pohon yang disebut CHAID (Detektor Interaksi Otomatis Chi-kuadrat)

Langkah-langkah Menghitung Chi-kuadrat untuk pembagian:

  1. Hitung Chi-kuadrat untuk masing-masing node dengan menghitung deviasi untuk Keberhasilan dan Kegagalan keduanya
  2. Menghitung Chi-kuadrat Pemisahan menggunakan Jumlah seluruh Chi-kuadrat keberhasilan dan Kegagalan setiap simpul pemisahan

Contoh: Mari kita gunakan contoh di atas yang telah kita gunakan untuk menghitung Gini.

Terbagi berdasarkan Gender:

  1. Pertama kita mengisi node Female, Isi nilai sebenarnya untuk “ Main Kriket” dan  “Tidak Main Kriket” , ini masing-masing adalah 2 dan 8.
  2. Hitung nilai yang diharapkan untuk “ Main Kriket” dan “ Tidak Main Kriket” , ini akan menjadi 5 untuk keduanya karena simpul induk memiliki probabilitas 50% dan kami telah menerapkan probabilitas yang sama pada hitungan Wanita (10).
  3. Hitung penyimpangan dengan menggunakan rumus, Aktual – Ekspektasi. Ini untuk “ Main Kriket” (2 – 5 = -3) dan untuk “ Tidak bermain kriket” (8 – 5 = 3).
  4. Hitung Chi-kuadrat dari simpul “ Main Kriket ” dan “ Tidak Main Kriket ” menggunakan rumus dengan rumus = ((Aktual – Diharapkan)^2 / Diharapkan)^1/2 . Anda dapat merujuk tabel di bawah ini untuk perhitungan.
  5. Ikuti langkah serupa untuk menghitung nilai Chi-kuadrat untuk simpul Pria.
  6. Sekarang tambahkan semua nilai Chi-kuadrat untuk menghitung Chi-kuadrat untuk Gender terpisah.


Berpisah di Kelas:

Lakukan langkah perhitungan serupa untuk pembagian Kelas dan Anda akan mendapatkan tabel di bawah ini.

Di atas, Anda dapat melihat bahwa Chi-square juga mengidentifikasi kesenjangan gender yang lebih signifikan dibandingkan dengan Kelas.

Perolehan Informasi:

Lihatlah gambar di bawah dan pikirkan node mana yang dapat dijelaskan dengan mudah. Saya yakin, jawaban Anda adalah C karena memerlukan lebih sedikit informasi karena semua nilainya serupa. Sebaliknya, B membutuhkan lebih banyak informasi untuk mendeskripsikannya dan A membutuhkan informasi yang maksimal. Dengan kata lain, kita dapat mengatakan bahwa C adalah simpul Murni, B kurang murni, dan A lebih tidak murni.

Sekarang, kita dapat menyimpulkan bahwa node yang lebih sedikit tidak murni memerlukan lebih sedikit informasi untuk mendeskripsikannya. Dan, simpul yang lebih tidak murni memerlukan lebih banyak informasi. Teori informasi adalah ukuran untuk menentukan tingkat disorganisasi dalam sistem yang dikenal sebagai Entropi. Jika sampel benar-benar homogen, maka entropinya nol dan jika sampel terbagi rata (50% – 50%), maka entropinya satu.

Entropi dapat dihitung menggunakan rumus: -

Di sini p dan q masing-masing adalah probabilitas keberhasilan dan kegagalan pada node tersebut. Entropi juga digunakan dengan variabel target kategorikal. Ia memilih pemisahan yang memiliki entropi terendah dibandingkan dengan node induk dan pemisahan lainnya. Semakin kecil entropinya, semakin baik.

Langkah-langkah menghitung entropi untuk pemisahan:

  1. Hitung entropi node induk
  2. Hitung entropi setiap node pemisahan dan hitung rata-rata tertimbang dari semua sub-node yang tersedia dalam pemisahan.

Contoh:  Mari gunakan metode ini untuk mengidentifikasi pemisahan terbaik untuk contoh siswa.

  1. Entropi untuk simpul induk = -(15/30) log2 (15/30) – (15/30) log2 (15/30) = 1 . Di sini 1 menunjukkan bahwa itu adalah simpul yang tidak murni.
  2. Entropi untuk simpul Perempuan = -(2/10) log2 (2/10) – (8/10) log2 (8/10) = 0,72 dan untuk simpul laki-laki, -(13/20) log2 (13/20) – ( 20/7) log2 (20/7) = 0,93
  3. Entropi untuk pemisahan Gender = Entropi tertimbang sub-node = (10/30)*0,72 + (20/30)*0,93 = 0,86
  4. Entropi untuk node Kelas IX, -(14/6) log2 (14/6) – (14/8) log2 (14/8) = 0,99 dan untuk node Kelas X, -(16/9) log2 (16/9) – (16/7) log2 (16/7) = 0,99.
  5. Entropi untuk Kelas terpisah = (14/30)*0,99 + (16/30)*0,99 = 0,99

Pengurangan Varians

Sampai saat ini, kita telah membahas algoritma untuk variabel target kategorikal. Pengurangan varians adalah algoritma yang digunakan untuk variabel target kontinu (masalah regresi). Algoritma ini menggunakan rumus standar varians untuk memilih pemisahan terbaik. Pemisahan dengan varians yang lebih rendah dipilih sebagai kriteria untuk membagi populasi:

Bilah X di atas adalah nilai rata-rata, X adalah aktual dan n adalah jumlah nilai.

Langkah-langkah menghitung Varians:

  1. Hitung varians untuk setiap node.
  2. Hitung varians untuk setiap pemisahan sebagai rata-rata tertimbang dari setiap varians node.

  3. Rata-rata Node Pria = (13*1+7*0)/20=0,65 dan Varians = (13*(1-0.65)^2+7*(0-0.65)^2) / 20 = 0.23

  6. Rata-rata simpul Kelas X = (9*1+7*0)/16=0,56 dan Varians = (9*(1-0.56)^2+7*(0-0.56)^2) / 16 = 0.25

Menetapkan Batasan pada algoritma berbasis pohon

Hal ini dapat dilakukan dengan menggunakan berbagai parameter yang digunakan untuk mendefinisikan sebuah pohon. Pertama, mari kita lihat struktur umum pohon keputusan:

Parameter yang digunakan untuk mendefinisikan pohon dijelaskan lebih lanjut di bawah. Parameter yang dijelaskan di bawah ini tidak bergantung pada alatnya. Penting untuk memahami peran parameter yang digunakan dalam pemodelan pohon. Parameter ini tersedia dalam R & Python.

  1. Sampel minimum untuk pemisahan node
    • Menentukan jumlah minimum sampel (atau observasi) yang diperlukan dalam sebuah node untuk dipertimbangkan dalam pemisahan.
    • Digunakan untuk mengontrol pemasangan yang berlebihan. Nilai yang lebih tinggi mencegah model mempelajari hubungan yang mungkin sangat spesifik pada sampel tertentu yang dipilih untuk sebuah pohon.
    • Nilai yang terlalu tinggi dapat menyebabkan underfitting sehingga sebaiknya disetel menggunakan CV.
  2. Sampel minimum untuk node terminal (daun)
    • Mendefinisikan sampel minimum (atau observasi) yang diperlukan dalam node atau daun terminal.
    • Digunakan untuk mengontrol over-fitting yang mirip dengan min_samples_split.
    • Umumnya nilai yang lebih rendah harus dipilih untuk permasalahan kelas yang tidak seimbang karena wilayah dimana kelas minoritas akan menjadi mayoritas akan sangat kecil.
  3. Kedalaman maksimum pohon (kedalaman vertikal)
    • Kedalaman maksimum sebuah pohon.
    • Digunakan untuk mengontrol over-fitting karena kedalaman yang lebih tinggi akan memungkinkan model mempelajari hubungan yang sangat spesifik untuk sampel tertentu.
    • Sebaiknya disetel menggunakan CV.
  4. Jumlah maksimum node terminal
    • Jumlah maksimum simpul terminal atau daun dalam satu pohon.
    • Dapat didefinisikan sebagai pengganti max_kedalaman. Sejak pohon biner dibuat, kedalaman 'n' akan menghasilkan maksimal 2^n daun.
  5. Fitur maksimal yang perlu dipertimbangkan untuk pemisahan
    • Jumlah fitur yang perlu dipertimbangkan saat mencari pemisahan terbaik. Ini akan dipilih secara acak.
    • Sebagai aturan umum, akar kuadrat dari jumlah total fitur berfungsi dengan baik tetapi kita harus memeriksa hingga 30-40% dari jumlah total fitur.
    • Higher values can lead to over-fitting but depends on case to case.

Pruning in tree based algorithms

As discussed earlier, the technique of setting constraint is a greedy-approach. In other words, it will check for the best split instantaneously and move forward until one of the specified stopping condition is reached. Let’s consider the following case when you’re driving:

There are 2 lanes:

  1. A lane with cars moving at 80km/h
  2. A lane with trucks moving at 30km/h

At this instant, you are the yellow car and you have 2 choices:

  1. Take a left and overtake the other 2 cars quickly
  2. Keep moving in the present lane

Let’s analyze these choice. In the former choice, you’ll immediately overtake the car ahead and reach behind the truck and start moving at 30 km/h, looking for an opportunity to move back right. All cars originally behind you move ahead in the meanwhile. This would be the optimum choice if your objective is to maximize the distance covered in next say 10 seconds. In the later choice, you sale through at same speed, cross trucks and then overtake maybe depending on situation ahead. Greedy you!

This is exactly the difference between normal decision tree & pruning. A decision tree with constraints won’t see the truck ahead and adopt a greedy approach by taking a left. On the other hand if we use pruning, we in effect look at a few steps ahead and make a choice.

So we know pruning is better. But how to implement it in decision tree? The idea is simple.

  1. We first make the decision tree to a large depth.
  2. Then we start at the bottom and start removing leaves which are giving us negative returns when compared from the top.
  3. Suppose a split is giving us a gain of say -10 (loss of 10) and then the next split on that gives us a gain of 20. A simple decision tree will stop at step 1 but in pruning, we will see that the overall gain is +10 and keep both leaves.

Note that sklearn’s decision tree classifier does not currently support pruning. Advanced packages like xgboost have adopted tree pruning in their implementation. But the library rpart in R, provides a function to prune. Good for R users!

7. What are ensemble methods in tree based algorithms ?

The literary meaning of word ‘ensemble’ is group. Ensemble methods involve group of predictive models to achieve a better accuracy and model stability. Ensemble methods are known to impart supreme boost to tree based models.

Like every other model, a tree based algorithm also suffers from the plague of bias and variance. Bias means, ‘how much on an average are the predicted values different from the actual value.’ Variance means, ‘how different will the predictions of the model be at the same point if different samples are taken from the same population’.

You build a small tree and you will get a model with low variance and high bias. How do you manage to balance the trade off between bias and variance ?

Normally, as you increase the complexity of your model, you will see a reduction in prediction error due to lower bias in the model. As you continue to make your model more complex, you end up over-fitting your model and your model will start suffering from high variance.

A champion model should maintain a balance between these two types of errors. This is known as the trade-off management of bias-variance errors. Ensemble learning is one way to execute this trade off analysis.

Some of the commonly used ensemble methods include: Bagging, Boosting and Stacking. In this tutorial, we’ll focus on Bagging and Boosting in detail.

8. What is Bagging? How does it work?

Bagging is an ensemble technique used to reduce the variance of our predictions by combining the result of multiple classifiers modeled on different sub-samples of the same data set. The following figure will make it clearer:


The steps followed in bagging are:

  1. Create Multiple DataSets:
    • Sampling is done with replacement on the original data and new datasets are formed.
    • The new data sets can have a fraction of the columns as well as rows, which are generally hyper-parameters in a bagging model
    • Taking row and column fractions less than 1 helps in making robust models, less prone to overfitting
  2. Build Multiple Classifiers:
    • Classifiers are built on each data set.
    • Generally the same classifier is modeled on each data set and predictions are made.
  3. Combine Classifiers:
    • The predictions of all the classifiers are combined using a mean, median or mode value depending on the problem at hand.
    • The combined values are generally more robust than a single model.

Note that, here the number of models built is not a hyper-parameters. Higher number of models are always better or may give similar performance than lower numbers. It can be theoretically shown that the variance of the combined predictions are reduced to 1/n (n: number of classifiers) of the original variance, under some assumptions.

There are various implementations of bagging models. Random forest is one of them and we’ll discuss it next.

9. What is Random Forest ? How does it work?

Random Forest is considered to be a panacea of all data science problems. On a funny note, when you can’t think of any algorithm (irrespective of situation), use random forest!

Random Forest is a versatile machine learning method capable of performing both regression and classification tasks. It also undertakes dimensional reduction methods, treats missing values, outlier values and other essential steps of data exploration, and does a fairly good job. It is a type of ensemble learning method, where a group of weak models combine to form a powerful model.

How does it work?

In Random Forest, we grow multiple trees as opposed to a single tree in CART model (see comparison between CART and Random Forest here, part1 and part2). To classify a new object based on attributes, each tree gives a classification and we say the tree “votes” for that class. The forest chooses the classification having the most votes (over all the trees in the forest) and in case of regression, it takes the average of outputs by different trees.

It works in the following manner. Each tree is planted & grown as follows:

  1. Assume number of cases in the training set is N. Then, sample of these N cases is taken at random but with replacement. This sample will be the training set for growing the tree.
  2. If there are M input variables, a number m<M is specified such that at each node, m variables are selected at random out of the M. The best split on these m is used to split the node. The value of m is held constant while we grow the forest.
  3. Each tree is grown to the largest extent possible and  there is no pruning.
  4. Predict new data by aggregating the predictions of the ntree trees (i.e., majority votes for classification, average for regression).

To understand more in detail about this algorithm using a case study, please read this article “Introduction to Random forest – Simplified“.

Advantages of Random Forest

  • This algorithm can solve both type of problems i.e. classification and regression and does a decent estimation at both fronts.
  • One of benefits of Random forest which excites me most is, the power of handle large data set with higher dimensionality. It can handle thousands of input variables and identify most significant variables so it is considered as one of the dimensionality reduction methods. Further, the model outputs Importance of variable, which can be a very handy feature (on some random data set).
  • It has an effective method for estimating missing data and maintains accuracy when a large proportion of the data are missing.
  • It has methods for balancing errors in data sets where classes are imbalanced.
  • The capabilities of the above can be extended to unlabeled data, leading to unsupervised clustering, data views and outlier detection.
  • Random Forest involves sampling of the input data with replacement called as bootstrap sampling. Here one third of the data is not used for training and can be used to testing. These are called the out of bag samples. Error estimated on these out of bag samples is known as out of bag error. Study of error estimates by Out of bag, gives evidence to show that the out-of-bag estimate is as accurate as using a test set of the same size as the training set. Therefore, using the out-of-bag error estimate removes the need for a set aside test set.

Disadvantages of Random Forest

  • It surely does a good job at classification but not as good as for regression problem as it does not give precise continuous nature predictions. In case of regression, it doesn’t predict beyond the range in the training data, and that they may over-fit data sets that are particularly noisy.
  • Random Forest can feel like a black box approach for statistical modelers – you have very little control on what the model does. You can at best – try different parameters and random seeds!

10. What is Boosting? How does it work?

Definition: The term ‘Boosting’ refers to a family of algorithms which converts weak learner to strong learners.

Let’s understand this definition in detail by solving a problem of spam email identification:

How would you classify an email as SPAM or not? Like everyone else, our initial approach would be to identify ‘spam’ and ‘not spam’ emails using following criteria. If:

  1. Email has only one image file (promotional image), It’s a SPAM
  2. Email has only link(s), It’s a SPAM
  3. Email body consist of sentence like “You won a prize money of $ xxxxxx”, It’s a SPAM
  4. Email from our official domain “Analyticsvidhya.com” , Not a SPAM
  5. Email from known source, Not a SPAM

Above, we’ve defined multiple rules to classify an email into ‘spam’ or ‘not spam’. But, do you think these rules individually are strong enough to successfully classify an email? No.

Individually, these rules are not powerful enough to classify an email into ‘spam’ or ‘not spam’. Therefore, these rules are called as weak learner.

To convert weak learner to strong learner, we’ll combine the prediction of each weak learner using methods like:

  • Using average/ weighted average
  • Considering prediction has higher vote

For example:  Above, we have defined 5 weak learners. Out of these 5, 3 are voted as ‘SPAM’ and 2 are voted as ‘Not a SPAM’. In this case, by default, we’ll consider an email as SPAM because we have higher(3) vote for ‘SPAM’.

How does it work?

Now we know that, boosting combines weak learner a.k.a. base learner to form a strong rule. An immediate question which should pop in your mind is, ‘How boosting identify weak rules?‘

To find weak rule, we apply base learning (ML) algorithms with a different distribution. Each time base learning algorithm is applied, it generates a new weak prediction rule. This is an iterative process. After many iterations, the boosting algorithm combines these weak rules into a single strong prediction rule. This is how the ensemble model is built.

Here’s another question which might haunt you, ‘How do we choose different distribution for each round?’

For choosing the right distribution, here are the following steps:

Step 1:  The base learner takes all the distributions and assign equal weight or attention to each observation.

Step 2: If there is any prediction error caused by first base learning algorithm, then we pay higher attention to observations having prediction error. Then, we apply the next base learning algorithm.

Step 3: Iterate Step 2 till the limit of base learning algorithm is reached or higher accuracy is achieved.

Finally, it combines the outputs from weak learner and creates  a strong learner which eventually improves the prediction power of the model. Boosting pays higher focus on examples which are mis-classiﬁed or have higher errors by preceding weak rules.
There are many boosting algorithms which impart additional boost to model’s accuracy. In this tutorial, we’ll learn about the two most commonly used algorithms i.e. Gradient Boosting (GBM) and XGboost.

12. Working with GBM in R and Python

Before we start working, let’s quickly understand the important parameters and the working of this algorithm. This will be helpful for both R and Python users. Below is the overall pseudo-code of GBM algorithm for 2 classes:

1. Initialize the outcome
2. Iterate from 1 to total number of trees
  2.1 Update the weights for targets based on previous run (higher for the ones mis-classified)
  2.2 Fit the model on selected subsample of data
  2.3 Make predictions on the full set of observations
  2.4 Update the output with current results taking into account the learning rate
3. Return the final output.

This is an extremely simplified (probably naive) explanation of GBM’s working. But, it will help every beginners to understand this algorithm.

Lets consider the important GBM parameters used to improve model performance in Python:

  1. learning_rate
    • This determines the impact of each tree on the final outcome (step 2.4). GBM works by starting with an initial estimate which is updated using the output of each tree. The learning parameter controls the magnitude of this change in the estimates.
    • Lower values are generally preferred as they make the model robust to the specific characteristics of tree and thus allowing it to generalize well.
    • Lower values would require higher number of trees to model all the relations and will be computationally expensive.
  2. n_estimators
    • The number of sequential trees to be modeled (step 2)
    • Though GBM is fairly robust at higher number of trees but it can still overfit at a point. Hence, this should be tuned using CV for a particular learning rate.
  3. subsample
    • The fraction of observations to be selected for each tree. Selection is done by random sampling.
    • Values slightly less than 1 make the model robust by reducing the variance.
    • Typical values ~0.8 generally work fine but can be fine-tuned further.

Apart from these, there are certain miscellaneous parameters which affect overall functionality:

  1. loss
    • It refers to the loss function to be minimized in each split.
    • It can have various values for classification and regression case. Generally the default values work fine. Other values should be chosen only if you understand their impact on the model.
  2. init
    • This affects initialization of the output.
    • This can be used if we have made another model whose outcome is to be used as the initial estimates for GBM.
  3. random_state
    • The random number seed so that same random numbers are generated every time.
    • This is important for parameter tuning. If we don’t fix the random number, then we’ll have different outcomes for subsequent runs on the same parameters and it becomes difficult to compare models.
    • It can potentially result in overfitting to a particular random sample selected. We can try running models for different random samples, which is computationally expensive and generally not used.
  4. verbose
    • The type of output to be printed when the model fits. The different values can be:
      • 0: no output generated (default)
      • 1: output generated for trees in certain intervals
      • >1: output generated for all trees
  5. warm_start
    • This parameter has an interesting application and can help a lot if used judicially.
    • Using this, we can fit additional trees on previous fits of a model. It can save a lot of time and you should explore this option for advanced applications
  6. presort 
    •  Select whether to presort data for faster splits.
    • It makes the selection automatically by default but it can be changed if needed.
